# 👔 Tech Market Analytics | Executive Brief Engine

An end-to-end data harvesting and visualization pipeline that extracts unstructured recruitment data from web DOM objects, normalizes compensation metrics, and renders publication-ready executive dashboards.

## 🚀 Features
* **DOM Parsing Engine:** Emulates dynamic HTML data ingestion utilizing `BeautifulSoup` to process complex job card clusters.
* **Data Cleansing Core:** Strips non-numeric characters, handles structure transformations, and exports clean logs to `scraped_job_market_analytics.csv`.
* **Annual Compensation Index:** Provides a descending rank profile of job titles mapped to direct-label currency vectors.
* **Workplace Model Matrix:** Overlays high-density distribution violin profiles with categorical stripplots to assess salary spread across Remote, Hybrid, and On-Site paradigms.

## 🛠️ Tech Stack
* **Web Scraping:** BeautifulSoup4
* **Data Science Infrastructure:** Pandas, NumPy
* **Visualization Suite:** Matplotlib, Seaborn
